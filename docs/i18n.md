# Gateway internationalisation

The gateway negotiates human-readable API error messages with the standard
`Accept-Language` request header. English (`en`) is the fallback, and Japanese
(`ja`, including regional tags such as `ja-JP`) is supported.

Only prose generated by the gateway is translated. Stable `error.code` values,
Rocket.Chat `upstream` identifiers, and structured `details` are never changed,
so clients can continue to branch on them independently of language. A raw
message forwarded from Rocket.Chat remains in its original language.

Error responses include `Content-Language` and `Vary: Accept-Language`. Add new
gateway messages to both catalogs in `apps/gateway/src/i18n/i18n.ts` and create
them with `ApiException.localized(...)`.
